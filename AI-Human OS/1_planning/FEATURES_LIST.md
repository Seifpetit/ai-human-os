# FEATURES_LIST.md

---

## 1. Lobby Screen (Game Entry Hub)

- **purpose:** Allow players to land in a simple screen where they can choose how to start playing.
- **reason_now:** This is the central entry point required to access all gameplay modes (solo or multiplayer).
- **priority:** high
- **status:** selected

---

## 2. Create Multiplayer Room

- **purpose:** Let a player create a new game session that others can join.
- **reason_now:** Core requirement for multiplayer interaction and initiating shared gameplay.
- **priority:** high
- **status:** selected

---

## 3. Join Multiplayer Room

- **purpose:** Allow a player to enter an existing room using a simple identifier (e.g. code or link).
- **reason_now:** Multiplayer is incomplete without the ability to join sessions created by others.
- **priority:** high
- **status:** candidate

---

## 4. Solo Play Mode

- **purpose:** Let a player start a game alone without needing multiplayer setup.
- **reason_now:** Provides instant access to gameplay and testing without dependency on other players.
- **priority:** high
- **status:** candidate

---

## 5. Touch Interaction Gameplay

- **purpose:** Enable players to tap/click to create gravity wells during the game.
- **reason_now:** This is the core interaction mechanic of the game and must work on touch devices.
- **priority:** high
- **status:** candidate

---

## 6. Basic Multiplayer Gameplay Session

- **purpose:** Allow multiple players in the same room to interact with the same ball in real time.
- **reason_now:** This is the core experience of the game (shared physics influence).
- **priority:** high
- **status:** candidate

---

## 7. Game End Detection

- **purpose:** Detect when a match finishes (e.g. goal reached or condition met).
- **reason_now:** Required to transition players out of gameplay cleanly.
- **priority:** medium
- **status:** candidate

---

## 8. Return to Lobby After Game

- **purpose:** Automatically or manually bring players back to the lobby after a match ends.
- **reason_now:** Keeps the loop simple and avoids dead-end states after gameplay.
- **priority:** medium
- **status:** candidate

---

## 9. Replay Option

- **purpose:** Allow players to quickly restart a match from the end screen.
- **reason_now:** Supports fast iteration and continuous play without friction.
- **priority:** medium
- **status:** candidate

---

## 10. Web Game Access (Browser Play)

- **purpose:** Allow the game to run directly in the browser without installation.
- **reason_now:** Matches the constraint of fast access and easy multiplayer sharing.
- **priority:** high
- **status:** candidate

---
