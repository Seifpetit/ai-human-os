FEATURE DEFINITION (CRITICAL)
----------------------------------------

A feature is a USER-LEVEL capability.

- It must describe what the user can do or experience
- It must NOT describe internal systems or technical components

Examples:

VALID:
- "Join a multiplayer game session"
- "Create and interact with gravity wells"
- "See the game state rendered on screen"

INVALID:
- "Real-time sync system"
- "Physics engine"
- "State broadcast pipeline"
- "Latency handling model"

If a concept is purely internal, DO NOT list it as a feature.
