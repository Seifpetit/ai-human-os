# Multiplayer Game / AI-Human OS

The current product in this repository is the `AI-Human OS` clarity engine.

It is a screen-based flow that ends at Screen 4 with a build blueprint.

## Current Product

Start the current product with:

```bash
npm run console:api
npm run console:ui
```

Open `http://127.0.0.1:5174`.

The live product is now organized under:

- [AI-Human OS/product/](AI-Human%20OS/product/)

## Product Flow

```text
Raw Intent
-> Interrogation
-> Verification
-> Build Blueprint
```

The product ends at Screen 4. It does not continue into live code generation.
